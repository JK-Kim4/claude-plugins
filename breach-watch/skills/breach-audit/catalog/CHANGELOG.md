# 카탈로그 변경 이력

버전 규칙은 SKILL.md '버전 규칙' 참고. 최신이 위.

## 1.0.0 — 2026-11-07

첫 카탈로그. 2025-01 ~ 2026-11-07 공개 사건을 국내·해외·AI 관여 세 갈래로 조사했다.

- 사건 85건(국내 21, 해외 64), 점검 57개, 카테고리 12개.
- AI 관여: confirmed 32, reported 4, none-reported 49.

조사에서 보인 경향:

- **AI가 새 구멍을 만든 게 아니라 옛 구멍을 더 빨리 찾는다.** AI 관여가 확인된 공격도 들어온 곳은 노출된 관리 포트, 기본 자격증명, 하드코딩 비밀, 미패치 서버였다(FortiGate 600대, JADEPUFFER, 2026-09 AI 공격 조직). 국내 금융사 연쇄 침해(2026-09~)도 AI 도구 흔적이 보도됐지만 성공 원인은 본인확인·인가 누락과 테스트 페이지 방치였다.
- **국내는 키 관리와 인가 누락이 반복된다.** 쿠팡 서명키, 티빙 소스 속 AWS 키, SKT 평문 계정, KT 공유 인증서, 금융권·G마켓·대신증권 API 인가 누락.
- **해외는 SaaS 토큰과 CI 공급망이 주 경로다.** Salesloft Drift → Gainsight → Klue로 이어진 OAuth 토큰 연쇄, Nx → Trivy → TanStack으로 이어진 pull_request_target 악용.
- **AI 개발 도구 자체가 새 공격면이 됐다.** MCP 서버, 코딩 에이전트 권한, CI 안의 AI 에이전트, 에이전트 스킬 마켓.
