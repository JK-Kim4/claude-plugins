# 쉬운 말 표

본문(개발자용 근거 칸 밖)에서는 왼쪽 말을 쓴다. 원래 용어가 꼭 필요하면 `<span class="term">쉬운 말 <small>(용어)</small></span>`로 한 번만 붙이고, '낯선 말 풀이'에 넣는다.

## 판정·심각도

| 원래 | 본문 |
|---|---|
| FAIL | 열려 있음 |
| PARTIAL | 반쯤 막힘 |
| MANUAL | 확인 필요 |
| PASS | 잘 돼 있음 |
| N/A | 해당 없음 |
| critical | 아주 위험 |
| high | 위험 |
| medium | 주의 |
| low | 참고 |

## 쓰는 법

- **결과를 먼저 말한다.** ❌ "카카오 이메일 검증 플래그 미확인" ✅ "남이 관리자 열쇠를 가져갈 수 있어요"
- **한 줄에 하나.** "~하고 ~해서 ~해요"처럼 이어 쓰지 않는다. 둘로 나눈다.
- **해요체.** 문장 끝은 "~해요", "~예요". 명사로 끝내도 된다("로그 보관 14일").
- **숫자는 정확히.** 반올림하거나 "많이"로 바꾸지 않는다. 조건이 있으면 떼지 않는다("운영 DB에 관리자 이메일 계정이 없으면").
- **실제 사고 이름을 붙인다.** "쿠팡(2025)도 도장이 새서 뚫렸어요"처럼 한 줄로. 사고 이름은 낯선 말이 아니다.
