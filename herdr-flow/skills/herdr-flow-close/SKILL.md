# 마무리

`<skills>`는 이 스킬 디렉터리의 부모다(플러그인 설치면 `<plugin>/skills`). 공용 규칙·스크립트는 `<skills>/herdr-flow/`에 있다.

먼저 읽을 것: `<skills>/herdr-flow/shared/rules.md` 2절(세션)·5절(체크리스트)·6절(사실과 대조). herdr 명령과 스크립트는 샌드박스 밖에서 실행한다.

## 1. 끝났는지 먼저 계산

「끝났다」고 말하기 전에 계산한다.

1. 체크리스트가 있으면 공유 기록 `log`를 받아 단계별 마지막 상태(마지막 `start`/`done`/`block`)를 계산한다. 미완료(진행 중·막힘·대기·기록 없음) 단계를 센다.
2. `plan.md` 단계 표와 대조한다. 체크리스트에 없는 단계, 단계 표에 없는 체크리스트 단계가 있는지.
3. **완료 기준을 원천에서 다시 확인한다**(관찰 조건: 운영 replica 값, 배포된 태그·이미지, PR 머지 상태, 테스트 결과). 앞 대조의 값을 옮기지 않고 지금 읽는다. 읽은 시각을 붙인다.

미완료가 0이 아니거나 완료 기준이 안 맞으면 「끝」이라고 하지 않는다. 남은 단계와 이유를 그대로 보고하고, 남겨 둘지(후속으로 미룸)·이어서 할지 사용자에게 하나만 묻는다.

## 2. 하위 세션 정리

```bash
<skills>/herdr-flow/scripts/ctx.sh <작업 약어>-
<skills>/herdr-flow/scripts/close.sh <이름> <작업 트리 경로 ...>
```

- 세션마다 넘긴 작업 트리에 커밋 안 된 변경·push 안 된 커밋이 없는지 `close.sh`가 본다. 있으면 닫지 않고, 그 변경이 무엇인지 확인해 사용자에게 보고한다(버릴지 커밋할지는 사용자 결정).
- `working` 세션은 닫지 않는다. 사용자가 만든 탭, 자기 탭은 닫지 않는다.
- 이 세션이 건 백그라운드 작업을 멈춘다: INBOX Monitor, `wake-at.sh`, `run_in_background` 작업(TaskStop). 계속 필요한 것(운영 감시 회차 등)이 남았으면 1절 「남은 단계」로 보고한다.
- 인계 문서·체크리스트의 하위 세션 표에 「닫음」.

## 3. 작업 트리·브랜치

- 머지가 끝나고 깨끗한 git worktree만 정리를 제안한다(`git worktree remove`). 머지 안 된 브랜치, 변경이 남은 트리는 지우지 않는다.
- 지우기는 사용자에게 목록을 보이고 승인을 받은 뒤에 한다(`herdr-flow-gate` 3절 기준).

## 4. 기록 정리

1. `plan.md`: 상태 「끝」, 단계 표 상태, 완료 기준 줄에 확인한 값과 시각. 하지 않은 일은 「나중에 할 일」·「후속으로 미룬 것」으로.
2. `decisions.md`: 대화에만 있던 결정이 남았으면 옮긴다.
3. 체크리스트: 마지막 상태가 모두 `done`·`skip`인지, `history`에 「마무리」 행, 재생성·재게시(`clerk` 서브에이전트에 넘겨도 된다).
4. `HANDOFF.md`: 다음 세션이 없더라도 마지막 상태 한 장으로 다시 쓴다(지금 상태, 끝난 것, 남은 것, 닫은 세션). 지난 인계 문서는 `notes/`로.
5. 사용자가 쓰는 장기 기록(메모리·티켓)이 있으면 이 작업 줄을 「끝」과 진입점 경로로 갱신한다.

## 5. 범위 밖 발견

작업 중 나온 범위 밖 발견(다른 버그, 위험한 설정, 문서와 코드 불일치)은 결과 문서에 섞지 않는다. 사용자에게 따로 목록으로 보고하고 티켓을 제안한다. 지금 운영 위험이면 맨 위에.
