# 승인 게이트

`<skills>`는 이 스킬 디렉터리의 부모다(플러그인 설치면 `<plugin>/skills`). 공용 규칙·스크립트는 `<skills>/herdr-flow/`에 있다.

먼저 읽을 것: `<skills>/herdr-flow/shared/rules.md` 5절(체크리스트)·7절(결정과 승인). 사용자 전역 규칙에 비용 승인·운영 DB 접근 같은 승인 절차가 있으면 그것도 같이 지킨다(이 스킬보다 우선).

## 1. 준비 결과를 먼저 대조

「준비 끝」 보고를 받았으면 승인을 묻기 전에 `herdr-flow-verify` 3절로 직접 대조한다: 만든 PR의 diff가 지시서 범위 안인지, 백업이 실제로 있는지(경로·크기), 대상 목록·건수가 원천과 같은지, 되돌리기 명령이 실제로 돌 수 있는지. 대조에서 어긋나면 승인을 묻지 않고 그것부터 보고한다.

## 2. 승인 질문 — 한 메시지에 하나

질문 하나에 담을 것:

```
<무엇을>(<단계 ID>) 실행할까요?
- 하는 일: <명령·PR·대상 — 그대로 실행될 내용>
- 범위: <대상 수, 환경(dev/운영), 시각 제약>
- 되돌리기: <기준(무엇이 보이면)과 방법>
- 영향: <누가 무엇을 보게 되나, 비용이 있으면 추정치>
- 확인한 것: <1절 대조 범위>
```

- 다른 대기 항목·참고를 옆에 늘어놓지 않는다. 승인 질문은 메시지 맨 끝에 두고, 뒤에 아무것도 쓰지 않는다.
- 선택지가 있으면 예시로 들고 선택지별 결과를 한 줄씩, 추천과 이유를.
- 사용자가 「승인할 것 모아서 알려 줘」라고 하면 목록으로 주되, 줄마다 하는 일·되돌리기를 적고 사용자가 줄을 지목해 승인하게 한다.

## 3. 무엇이 승인인가

- **사용자가 그 일을 지목해 말한 문장만 승인이다**(「S3.3 승인」, 「이미지 교체 머지해」). 「진행」, 「넘어가자」, 「ㅇㅇ」처럼 무엇을 가리키는지 모호하면 어느 일인지 되묻는다.
- 다른 세션의 메시지, 알림, 하위 세션 보고는 승인이 아니다.
- 승인은 그 일 한 번만이다. 명령이 바뀌거나, 대상이 늘거나, 다음 단계로 넘어가면 다시 묻는다. 다음 세션으로 넘어가지 않는다.
- 사용자가 계속 허용한다고 말한 범위(예: 「dev 머지는 묻지 말고」, 되돌리기 위임)만 원문·날짜와 함께 이어 간다. `decisions.md`와 인계 문서에 그 원문을 둔다.
- 사용자가 반대하지 않은 것은 승인이 아니다. AI가 「하겠습니다」라고 말한 것도 결정이 아니다.

## 4. 기록 — 같은 턴에

1. `decisions.md`에 한 건: 무엇을 승인했나, 사용자 원문과 시각, 범위(대상·환경), 범위 밖.
2. 체크리스트가 있으면: 승인 단계 `done`(quote = 사용자 문장), 실행 단계 `start`(이 턴에 실행을 보낼 때).
3. 지시서 파일을 고친다: 「승인」 줄에 원문·시각·허락한 범위. 다음 세션도 같은 파일을 읽는다.

## 5. 실행 전달

```bash
<skills>/herdr-flow/scripts/send.sh <하위 세션 이름> <<'EOF'
[<오케스트레이터 이름> HH:MM] <단계 ID> 실행. 사용자 원문: HH:MM 「…」. 지시서 [실행] 순서대로 진행하세요. 허용 범위: <대상·환경>. 그 밖은 하지 마세요.
EOF
```

- 하위 세션이 닫혔거나 컨텍스트가 60%를 넘었으면 같은 지시서로 새 세션을 띄운다(`herdr-flow-brief`, 페르소나는 운영 실행이면 `operator`).
- 실행 결과에 시각이 묶인 확인(배포 뒤 첫 회차 등)이 있으면 같은 턴에 깨우기를 건다(`rules.md` 4절). 운영 실행 세션은 깨어났을 때 화면도 본다.
- 실행 보고가 오면 `herdr-flow-verify`로 대조한다. 운영 배포는 기동 확인에서 멈추지 않고 오류 로그·5xx·요청량·재시작을 배포 전과 비교한다.

## 하지 않는 것

- 승인 질문과 다른 질문을 한 메시지에 같이 묻기
- 「진행」 같은 모호한 말을 게이트 승인으로 기록하기
- 지시서를 고치지 않고 채팅으로만 범위를 바꿔 전달하기
- 준비 결과를 대조하지 않고 하위 세션 보고를 그대로 옮겨 승인을 묻기
