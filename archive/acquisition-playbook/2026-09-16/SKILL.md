# acquisition-playbook — 소설비 신규 유입 실무 참조

원 출처: coreyhaines31/marketingskills(MIT)의 `referrals`·`signup` + kostja94/marketing-skills(MIT) 채널·cold-start 부문을 정독 후 소설비 맥락(무료·한국어 작가 타깃)으로 번안. 원본의 금전 인센티브·어필리에이트 커미션 절은 무료 서비스라 제외 — 유료화 시 원본 재참조.

## 1. 추천 루프 설계

```
트리거 시점 → 공유 행동 → 유입자 전환 → (보상) → 반복
```

- **소설비는 금전 보상형이 아니라 제품 내재형** — 작가가 자기 산출물(집필 기록·작품)을 공유하는 행위 자체가 홍보가 되게 한다. 보상은 금전이 아니라 정체성·성취 표현.
- **트리거 시점(고의도 순간)**: 첫 aha 직후 / 마일스톤 달성 직후(주간 기록·완주) / 좋은 경험 직후. 아무 때나 공유 버튼을 놓지 않고 이 순간에 놓는다.
- **공유 수단 효과 서열**(원본 실증): 1. 제품 안에서 바로 공유 > 2. 개인화 링크 > 3. 이메일 초대 > 4. SNS 공유 > 5. 코드. 소설비 1순위 = 집필 기록 카드(이미지) + UTM 링크.
- 루프 최적화 진단: 공유가 적으면 시점·마찰을 보고, 유입자가 전환 안 되면 **랜딩(공유물을 본 사람이 도착하는 화면)** 을 본다 — 공유자의 신뢰가 랜딩에 보여야 한다.
- 실증 수치(원본, 참고용): 추천 유입 사용자는 LTV 16~25% 높고 이탈 18~37% 낮다.

## 2. 유입 측정

- 공유물마다 UTM 부여, GA4 에서 일반 유입과 구분. 프로그램 건강: 최근 30일 활성 공유자 수 / 공유 경유 전환율. 사업 영향: 신규 중 공유 경유 비율.
- GA4 는 Production env 전용 — 로컬·프리뷰 미수집이 정상 ([[ga4-tracking-prod-env-only]]).

## 3. 가입 마찰 원칙 (signup 증류)

- **가치를 먼저 보여주고 가입은 나중에** — 비로그인으로 체험 가능한 표면(공개 페이지·무료 도구)을 늘린다. 단, 소설비 에디터 자체의 비로그인 체험은 iOS WebKit 미지원으로 공수 대비 효과 최저 판정(2026-08-19 리뷰) — 재검토 비권장.
- 필드 하나하나가 전환을 깎는다: 지금 꼭 필요한가 / 나중에 받을 수 있는가 / 추론 가능한가.
- 가입 직후 화면이 곧바로 활성화 행동(첫 집필)으로 이어지는지가 가입 최적화의 끝이다.

## 4. 검색·콘텐츠 유입

- **의도 일치 키워드 우선**: 도구형 검색("소설 쓰는 프로그램", "집필 타이머")은 전환 의도가 높다. 정보형("웹소설 공모전 일정")은 volume 은 크지만 착지 자산(비로그인 공개 페이지)이 있어야 받는다.
- 공개 자산 = 리드 마그넷: 공모전 캘린더·글자수/원고지 계산기 같은 비로그인 무료 표면. CTA 는 본문 하단 1회 — 과한 팝업 금지.
- 콘텐츠 부식은 월 1회 점검(트래픽 감소 페이지 갱신).

## 5. 국내 지형 체크리스트 (매 전략마다 대조)

- [ ] **네이버**: 이 타깃(작가 지망생)의 정보 탐색은 네이버 카페·블로그 비중이 크다(비율은 검증 필요) — 구글 SEO 만으로 유입 추정하지 않는다.
- [ ] **X 작가 커뮤니티**: 글자수 인증·마감 문화가 이미 존재(관찰 근거, 포맷은 조사 필요) — 새 문화를 만들지 말고 기존 문화에 올라탈 것. 공유 카드 포맷을 그 문화에 맞춘다.
- [ ] **도달 채널 실측**: 이메일 보유율·수신동의, 알림톡(템플릿 심사+건당 과금+채널 추가 필요), web push(iOS 사파리 제약). 채널 없는 발송 전략은 종이 전략이다.
- [ ] **경쟁 착지 자산**: 같은 검색어를 받는 기존 포털(공모전이면 씽굿·위비티)과 차별점이 있는가 — 없으면 그 키워드는 후순위.

## 6. 소규모 단계 주의

- 신규 유입이 월 한 자릿수인 단계에선 채널 다각화보다 **한 루프(공유 카드)의 완성도**가 먼저다.
- 유입 실험의 성패 판정도 퍼센트가 아니라 건별 관찰로.
