# 그림 고르기

장면마다 왼쪽 그림은 **질문 하나에 답하는 그림 하나**다. 독자가 그림만 보고 "아, 이런 경우엔 이렇게 보이는구나"를 알아야 한다. 틀(`templates/book.html`)에 모든 그림 부품이 있다.

## 무엇을 설명하나 → 어떤 그림

| 설명할 것 | 그림 | 틀의 클래스 |
|---|---|---|
| 조건에 따라 앱 화면의 목록·카드·버튼이 달라짐 | 휴대폰 목업 | `.phone` + `.card`(`me` 주인공, `full` 덮개 문구, `ghost` 목록에 없음) + `.ph-btn`(`off` 막힌 버튼) |
| 어드민·웹 페이지의 칸 값, 막힌 버튼 | 창 목업 | `.win` + `.win-row`(`win-hl` 눈여겨볼 칸) + `.win-btn` |
| 화면 한 칸에 보이는 숫자 하나의 정체 | 값 카드 | `.vcard` |
| 알림톡·슬랙·메일이 갔나 안 갔나 | 메시지 목업 | `.msgs` + `.msg`(`msg-me` 받는 쪽, `msg-miss` 안 간 메시지) |
| 셀 수 있는 수량(자리·재고·건수, 40칸 이하) | 칸 격자 | `.seatbox` + `.seats` + `.seat`(`t` 쓰인 칸, `r` 예약된 칸, `o` 남은 칸) |
| 서로 독립인 판정 규칙 여러 개 | 문 | `.gates` + `.gate`(`g1`~`g4` 색) |
| 한 건이 순서대로 거쳐 가는 단계, 중간에 멈추는 곳 | 흐름 | `ol.flow` + `.fstep`(`fs-stop` 멈춤, `fs-pass` 통과) |
| 같은 조건인데 결과가 다름, 또는 바뀌기 전과 후 | 나란히 | `.pair` + `.side` + `.lbl` |
| 한 건에 시간순으로 일어난 일 | 시간표 | `ol.timeline`(`warn` 문제, `good` 좋은 일) |
| 그동안 정한 것·안 정한 것 | 지금까지 | `ul.history` |
| 그림이 어떤 조건의 경우인지 | 조건 칩 | `.chips` + `.chip`(`ch-a`/`ch-b`/`ch-c` 값별 테두리) |

화면이 없는 주제(배치 작업, 정책, 데이터 흐름)는 흐름·문·칸 격자·시간표·나란히로 그린다. 휴대폰 목업을 억지로 넣지 않는다.

## 색의 뜻

색은 장식이 아니라 판정을 나타낸다. 한 문서 안에서 바꾸지 않는다.

| 색 | 뜻 | 쓰는 곳 |
|---|---|---|
| 해(`--sun`) | 조직 확인 필요 | 표지 확인 카드 `ask-c`, 판정 `ask`, 주인공 테두리 `me`, 정해 주세요 상자 |
| 장미(`--rose`) | 문제·멈춤·없음 | 표지 확인 카드 `bad-c`, 판정 `bad`, `ghost`, `fs-stop`, `msg-miss`, 시간표 `warn` |
| 잎(`--leaf`) | 정상·통과·남은 것 | 판정 `ok`, `fs-pass`, 남은 칸 `o`, 시간표 `good` |
| 하늘(`--sky`) | 중립·바탕 | 그림 쪽 배경, 기본 단계 |
| `--c1`~`--c6` | 뜻 없음 | 카드 표지 색, 쓰인 칸 |

## 그림 규칙

- **그림 속 숫자는 본문·근거와 같고, 원천 조회로 확인한 값이다.** 칸 격자의 칸 수, 종류별 칸 수, 카드에 적은 `18/16` 같은 값까지 다시 센다. `check/check.py`가 칸 수와 aria-label·제목 수가 다르면 잡는다.
- **칸 격자는 40칸 이하일 때만 한 칸씩 그린다.** 넘으면 `1칸 = 10건`처럼 단위를 제목에 적거나, 칸 격자 대신 숫자 칩을 쓴다.
- **주인공 하나만 `me`로 표시한다.** 이웃 카드는 "자리 있는 클럽"처럼 역할만 적는다.
- **없는 것은 `ghost`로 자리를 비워 그린다.** "목록에 없음", "안 감"을 빈칸으로 보여 주면 독자가 무엇이 빠졌는지 바로 본다.
- **화면 문구는 실제 화면 그대로 쓴다.** 덮개 문구(`data-badge`), 버튼 문구, 메시지 문구를 지어내지 않는다. 확인 못 하면 본문에 `미확인`을 적는다.
- **흐름은 7단계 이하.** 더 길면 장면을 둘로 나눈다.
- **새 부품이 필요하면 컴포넌트 접두사를 붙인다**(`tl-`, `bar-` …). `.seat`, `.card`, `.grid` 같은 짧은 이름을 다른 부품의 수식 클래스로 쓰면 스타일이 섞인다.
- **SVG가 꼭 필요하면** 글자가 선에 닿지 않게 하고, 색은 위 토큰만 쓴다.
