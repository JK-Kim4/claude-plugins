# 승인된 예시

모양·밀도·말투를 맞추는 데만 쓴다. 용어·숫자·장면 구성은 새 문서로 옮기지 않는다.

| 파일 | 주제 | 그림 | 볼 점 |
|---|---|---|---|
| `example-bread-alimtalk.html` | 가상 빵집 예약 앱에서 예약 확정 알림톡이 가고 안 가는 조건(전부 지어낸 데이터, 이 스킬만 보고 만든 시험본) | 메신저 화면 속 메시지, 웹 화면 목업, 칸 격자, 흐름(갈림길), 나란히 속 시간표 둘, 시간표, 지금까지 | 화면이 여럿인 주제의 장면 나누기, 같은 묶음을 다른 화면에서 다시 보는 쪽, 장면 수 합 = 대상 수, 표지 카드 3 = 질문 3 |

처음 만든 승인본(앱 목록 화면이 조건에 따라 달라지는 주제)은 사내 시스템 정보가 들어 있어 공개본에 넣지 않았다.
